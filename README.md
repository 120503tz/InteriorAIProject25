# 🏠 Interior AI

Beginner-friendly interior design app that lets users create room layouts, visualize them in 3D, get AI suggestions, and plan budgets — all in one place.

---

## 📌 Features

- 🛋️ **Room Layout Tool** – Drag and drop rooms and furniture
- 🧠 **AI Recommendations** – Get style and furniture suggestions
- 📐 **3D Visualization** – See your design in real-time 3D
- 💸 **Budget Planner** – Estimate the cost of your design
- 📦 **Material Catalog** – Browse furniture and décor
- 💾 **Save & Share** – Export and send your design

---

## 🚀 Getting Started

### Clone the Repo:
```bash
git clone https://github.com/your-username/interior-ai.git
cd interior-ai
```

### Install Dependencies:
```bash
npm install
```

### Run the App:
```bash
npm start
```

---

## 🛠 Tech Stack

- **React.js** – Frontend framework
- **React Router** – Page navigation
- **Three.js** – 3D rendering
- **Tailwind CSS** – Styling (optional)
- **Ollama** – Local AI engine (planned)
- **Supabase** – Backend storage (planned)
